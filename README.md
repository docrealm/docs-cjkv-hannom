Hán-Nôm Characters:
- Chữ Hán（𡨸漢 / 汉字）：也叫儒字（Chữ Nho／𡨸儒）、汉字（Hán Tự／漢字），越南用于书写外来的汉语词汇。
- Chữ Nôm（𡨸喃 / 喃字）: 越南历史上以汉字为基础构建的越南汉字，用于书写越南语的固有词汇等。
- Hán-Nôm（漢喃）：汉字、喃字统称，泛指越南历史上使用的汉字系统
